// OVERVIEW

Tetris is a puzzle game in which shapes made of four connected squares fall into a well. The player moves and rotates each piece so that it fits with the others, and every horizontal line that is completely filled disappears.

The rules can be learned in seconds, but the game never stops asking for decisions. As pieces fall faster, players have to plan ahead, read the shape of the stack and keep space open for the pieces still to come.

// HISTORY

Tetris was created in 1984 by Alexey Pajitnov, a researcher at the Dorodnitsyn Computing Centre of the Soviet Academy of Sciences in Moscow. The first version ran on an Electronika 60, a computer that could only display text, so the pieces were drawn with characters.

Copies spread across computers in the Soviet Union and Eastern Europe before versions were released in the West. The game became a worldwide phenomenon in 1989, when a version for Nintendo's new Game Boy handheld was released and packaged with the system in many regions.

ARCHIVE NOTE // HISTORICAL IMPACT

// HISTORICAL SIGNIFICANCE

Tetris showed that a game built from a handful of simple rules could hold players' attention for decades. It became one of the most widely played and ported video games ever made.

Its success on Game Boy also proved that short, flexible play sessions suited portable gaming, which helped shape handheld and later mobile game design.

# Gaming Map Revamp

An interactive, arcade-styled archive of video game history, explored through the mechanics that define how we play: **Explore, Solve, Jump, Build, Fight, Run, Survive**.

A revamp of [Gaming-Map](https://github.com/mikey101101/Gaming-Map). It's plain HTML, CSS and JavaScript with no build step and no libraries.

## Features

- **Boot screen**: an "Archive OS" loading sequence. Press Start or Enter.
- **Interactive star map**: 7 floating path nodes with animated connection lines, hover scanning and particle bursts.
- **Popups**: path popups list each genre and its games as clickable cartridges. Game files have Overview, Legacy and Mechanic Mix tabs.
- **Archive grid**: 27 game cards with 3D tilt and shine, filterable by path and sortable by year or title.
- **Timeline**: a draggable timeline of the pioneers (1952–1972) followed by every game in release order.
- **Versus mode**: compare any two games with an animated radar chart, tug-of-war bars and an auto-written verdict.
- **Which path are you?**: a 5-question quiz.
- **XP, levels and 10 achievements**, with toast popups. Progress is saved in the browser.
- **Search palette**: press `/` or `Ctrl/Cmd + K`.
- **Secret**: try the classic code ↑ ↑ ↓ ↓ ← → ← → B A.
- Optional 8-bit sound effects (off by default), a twinkling star field with shooting stars, parallax pixel landscapes and scanlines.
- Responsive down to phone width, and honours reduced-motion settings.

## Files

```
index.html          page structure
css/style.css       all styling and animations
js/data.js          paths, genres, games, pioneers, quiz, achievements
js/app.js           all interactivity
assets/img/*.png    original pixel art (generated by tools/make_sprites.py)
```

**Adding a game:** add an entry to `GAMES` in `js/data.js` and put its id in a genre's `games` list.

**Regenerating the pixel art:** run `python3 tools/make_sprites.py`.

## Run locally

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server
```

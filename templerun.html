// OVERVIEW

Temple Run is a mobile game in which an explorer steals an idol from a temple and is chased by creatures along an endless path. The character runs automatically, and the player swipes to turn, jump and slide.

The path never ends, so each run lasts until the player makes a mistake. Coins collected during runs can be spent on power-ups and new characters.

// HISTORY

Temple Run was created by Imangi Studios, a small studio run by Keith Shepherd and Natalia Luckyanova. It was released for iOS in 2011 and later became free to download.

The game became one of the most popular mobile games of its time, and an Android version followed in 2012. Its success led to spin-offs and a sequel.

ARCHIVE NOTE // HISTORICAL IMPACT

// HISTORICAL SIGNIFICANCE

Temple Run helped popularise the endless runner on smartphones, showing how touch controls could support fast action games.

Its short, repeatable runs suited how people play on mobile and influenced many games that followed.
